# Nitheesh's Portfolio

A beginner-friendly, responsive portfolio website using plain HTML and CSS.

## Preview on your phone or computer
Open `index.html` in a browser.

## Before publishing
- Add your GitHub and LinkedIn URLs.
- Add real project photos and repository links after you have them.
- Update project status from “idea / in progress” only when accurate.
- Avoid publishing your phone number, home address, student ID, or other private details.

## Publish free with GitHub Pages
1. Create/sign in to GitHub.
2. Create a **public** repository named `yourusername.github.io` (replace with your GitHub username).
3. Upload `index.html` to the repository root.
4. Open the repository's Settings → Pages and follow the publish instructions if prompted.
5. Your website URL will usually be `https://yourusername.github.io/`.

GitHub may take a few minutes to publish the first time.
